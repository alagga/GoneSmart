# Credits

GoneSmart is an independent community project for GoneMAD Music Player.

## Maintainer

- [alagga](https://github.com/alagga) — project direction, requirements, testing, releases and maintenance.

## Projects and services

GoneSmart would not be possible in its current form without:

- [GoneMAD Music Player](https://gonemadmusicplayer.blogspot.com/) by GoneMAD Software — the player GoneSmart extends.
- [JingMatrix/Vector](https://github.com/JingMatrix/Vector) and the libxposed ecosystem — rooted module runtime and modern Xposed API.
- [JingMatrix/LSPatch](https://github.com/JingMatrix/LSPatch) — experimental no-root module path.
- [ListenBrainz](https://listenbrainz.org/), [MetaBrainz](https://metabrainz.org/) and [MusicBrainz](https://musicbrainz.org/) — open music metadata and recommendation infrastructure.
- [Last.fm](https://www.last.fm/) — similar-track recommendation data used by Smart Auto-DJ.

Their names and trademarks remain the property of their respective owners. GoneSmart is not affiliated with or endorsed by these projects/services unless explicitly stated otherwise.

## AI-assisted development

GoneSmart is an AI-assisted coding project.

OpenAI ChatGPT has been used as a development assistant for implementation support, debugging, code review, documentation and release-workflow work. Product direction, feature requirements, testing, compatibility decisions and release decisions remain maintainer-driven.
