# GMMP localization and native-function audit — 28 September 2026

**Code audited:** `feature/multi-playlist-add`, after the maintainer accepted the complete Playlist folders feature on the tested GMMP **4.2.0** device. This is a **source-level audit**, grounded in the repository implementation and the earlier documented investigation of the supplied original GMMP 4.2.0 APK. It is **not** a claim that all 76 raw APK language codes, every skin, or every action listed below were newly exercised on a device during this audit. Green CI proves compile/pure regression tests, not live GMMP resource availability or interface grammar.

**Contract:** The companion app and its Logs/Help are English-only. Inside GMMP, show native terms from the *host player's* live `Resources` and current app-specific locale; preserve original native views, menus, actions, theme and state where possible. Use one central GoneSmart-only fallback file only for genuinely missing feature-owned concepts. The two required non-native concepts are the **Move** command and the **virtual Other Locations** group label (the latter is *not* a physical folder name). Do not translate a real user's folder or playlist name.

Exact idiom, gender/case, all plurals, RTL layout, and changes in future GMMP APKs are **not** proved by these checks. The `NativeGmmpUiText` resolver always prefers the current host's own resource when present and uses locale-neutral symbols for generic feature statuses rather than inventing detailed translated error sentences.

## 2. Native-function reuse audit

**Classification:** **NATIVE** means the code actually invokes an observed original GMMP API, uses the original native menu/View/dialog, or preserves its default behavior. **EXTENSION** means GoneSmart supplies behavior that no equivalent safe original API has been established to provide. **REVIEW** means a potentially relevant original API is documented, but its exact safe contract has **not** been verified; do not replace tested behavior by guessing obfuscated signatures.

| Function / interaction | Actual current native calls or controls | Own work / classification |
| --- | --- | --- |
| Smart Auto-DJ reading and track selection | GMMP local catalog/ArtistDao and queue objects, native Auto-DJ settings, original queue/session lifecycle. Injected selection hook yields matched **native local track IDs** to GMMP; unchanged native Auto-DJ is fallback. | **NATIVE + EXTENSION:** ListenBrainz/Last.fm lookups, normalization, local matching, ranking and bounded recommendation pool are GoneSmart's purpose; GMMP has no documented native replacement for these network-driven heuristics. |
| Smart DJ player status | Existing original full Now Playing playback-mode control, updated only when active and eligible. | **EXTENSION:** separate visual overlay, no new playback engine and no mini-player/queue badge. |

**Host-specific locale correction:** Smart DJ's injected status Toast initially used a GMMP **Application** context. To respect players that override language on their own active Activity, `GoneSmartStatusNotifier` now retains a **weak** reference to the actual host `MainActivity` observed through its already installed `onResume` hook and resolves native status resources from that foreground Activity when valid. Track Auto-DJ similarly keeps its originating GMMP menu Context for the bounded asynchronous request; it does not silently switch to the process-wide application locale. These fixes are source/CI-verifiable but a real GMMP in-app language-toggle smoke test is still required.

### 3. Outstanding questions and release-hardening gates

1. **Potential native playlist Move/save primitive — REVIEW:** map original `zo3` / `hp3.d` writer's complete live model initialization, new destination binding, relative URI handling and `x6.b`/scanner index lifecycle using the privately inspected *same* original GMMP 4.2.0 APK. Existing native editor save does normalize relative playlist paths, but that observation alone does not prove it can safely relocate a playlist without stale records. **Keep the currently tested durable native-delete/native-scan Move workflow until such a complete alternative is established**.
2. **Native folder context popup — REVIEW:** the wrapper already inflates GMMP's original translated Delete menu item and invokes original `py0.b`, but does not reuse a proven specific Files-tab folder-context-menu presenter. Replacing it requires identifying its real model and callback contract; current accepted UI is not evidence of that mapping.
3. **Native configured playlist root — REVIEW:** Current `PlaylistRootLocator.infer()` conservatively recognizes only `Environment.getExternalStorageDirectory()/gmmp/playlists`, verified against at least one original native playlist path. **This is not reading GMMP's actual configurable `playlist_saveLocation`.** The original native `vp3.F → va4.getValue()` preference delegate is known and already verified **inside original `sp3`/`fo3` create callbacks**, where a mismatch safely cancels creation. A general read-only pre-browser resolver for that delegate has **not** been proven/installed, so a non-default configured GMMP playlist directory may fail to enable GoneSmart's folder browser. Do not guess an arbitrary common ancestor or change GMMP's preference; implement a verified read-only preference resolver if broader custom-root support is required, then test a non-default root on-device.
4. **Exact locale grammar/accessibility — REVIEW:** native resource lookups and fallback mapping are source-verified, but all 74 new virtual-folder translations have not undergone independent native-speaker review; neither has every locale's multi-add aggregate plural phrasing, mixed RTL directionality or a live change of GMMP's own language override. Screen-reader narration of all injected controls is part of the locale/device smoke tests.
5. **Alternative GMMP skins/versions — REVIEW:** existing tests validate the maintainer's GMMP 4.2.0 device and current skin. Source cloning samples native typography, layout, item animator and palette, but cannot guarantee pixel-identical behavior for every alternative skin, custom animator or later obfuscated GMMP release.
6. **Status detail tradeoff:** detailed English explanations previously leaked into GMMP Toasts. Host-player generic localized errors and icons now avoid that leak; richer localized diagnosis would require a **verified relevant native GMMP sentence** or **explicit newly approved, linguistically reviewed GoneSmart translations for all supported host languages**. English engineering detail remains in companion logs when emitted and in Logcat.
7. **No release implied:** The maintainer accepted the folder feature on the tested device; this branch-level audit and its CI do not authorize a signed public release, merging to main, or claiming new testing for untried languages/screens.

### 4. Debug vs release feature availability after acceptance

The audit found another shipping gap: before this cleanup, the complete playlist folder UI and several native destination/adapter hooks still ran exclusively under `BuildConfig.DEBUG`, although accepted behavior was documented as feature-complete. The development branch now exposes the Playlist folders and grouping settings and installs the complete guarded folder/menu/adapter/create/move hook paths in **both** build variants, retaining passive native-save discovery and optional geometry probes as debug-only. This is a code/CI availability change, **not** evidence of new signed-release device testing. Do not restore the blanket debug-only gate when preparing v0.4.x.
